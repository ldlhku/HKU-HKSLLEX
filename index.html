About the lexicon

A resource for Hong Kong Sign Language

HKSLLEX is a collection of Hong Kong Sign Language data created as part of the documentation effort for the Knowledge Exchange project, “The Sound of Silence - A Journey through Deaf Culture in Hong Kong”.

This database organizes HKSL signs, English translations, videos, and associated research data for linguists, researchers, educators, and people interested in learning the language.

Get started

Access the data

For the downloaded browser, include the video/webp folder. Videos in MP4 format are also available in the video folder. The reduced MP4 and WebP videos are available on OSF; full high-definition videos are available on request.

You can also download the complete database and work directly with its data files.

Reference

Documentation & data format

The database structure is defined in data.schema.json. The human-readable schema describes its fields.

Data is stored in JSON format. A flattened CSV file with UTF-8 BOM is also provided for easy access.
